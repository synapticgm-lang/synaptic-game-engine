# How similar stories open (live game — 2026-08-15)

Used to replace the fixed registrar. Each SynapticGM bible now has its own covering rules; the writer generates the first page.

| Story type | How peers start | What we copy | What we do not copy |
|---|---|---|---|
| CYOA books / Choice of Games / Bandersnatch | Drop into the crisis. You already are someone. First beat is a choice, not a form. | PYOA `openingMode: scene` | Name / location / outfit questionnaire |
| Fallen London / Disco Elysium | Wake inside a moment. Identity arrives through play. | Seed place from the bible; let name wait | Session-0 dump |
| AI Dungeon / Hidden Door | Vivid generated open. Curated choices after. | Unique camera each New Game from the bible | Unstructured void with no premise |
| LitRPG / System apocalypse (Tao Wong, DCC) | Ordinary street, then the box as a *moment*. Progressive reveal. | Weave: street first, panel second | “Earth is being written into the System”; Confirm designation loop |
| Isekai summon | Arrive in the circle. Summoners talk. Clothes are a look-down. Origin is “where the light took you from.” | Weave in-world questions | System form before the stone is cold |
| Murder mystery | Body already on the rug. | Giltwood scene open | “Where does this open?” |
| Romance / wedding crisis | Door already knocking. | Rose-Gold scene open | Registrar before Julian knocks |
| Space horror | Bulkhead already failing. | Erebus scene open | Name-and-deck form |

**Covering rules (code):** PYOA/story = generate and play. LitRPG/isekai = generate, then harvest remaining facts from in-world answers (look down, someone asks your name). Never a global registrar.
