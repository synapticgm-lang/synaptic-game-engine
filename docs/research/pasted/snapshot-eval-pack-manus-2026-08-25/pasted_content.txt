Engine is source of truth. LLM is a read-only renderer.

SNAPSHOT in the GM situation packet is AUTHORITY for:
- current location
- crowd (present | none | unknown) and approximate size when tracked
- exits that exist (interior floor-plan doors/passages)
- scene props / containers that have been established
- who is present (named NPCs, companions, encounter)
- inventory item names the player actually has
- tracked time of day, weather, indoor/outdoor, tension when set

Pre-GM HARD GATE (no API spend if blocked):
- BLOCK: invented items the player tries to USE/DRAW/WIELD/possess; “the last/final/remaining box/crate/chest” when inventory + scene props + loose items do not support that container; absent companion; ungrounded Proper-Name talk (name not in present / companions / encounter).
- ALLOW: talking to a Proper Name that appeared in the LAST GM story beat (even if not yet on the roster).
- SKIP entirely: look-around / examine room; opening name-look-kit-location covers; room-layout questions (doors/windows); informational / “info or option” / panel asks.

PROSE WARDEN (after GM, regex repair, do not block the whole turn):
- Scrub “the last box / remaining crate / final chest” → a grounded rewrite (“the area” / “a box”) if SNAPSHOT has no such container.
- Scrub invented crowd size (“hundred people”) when tracked size is small.
- Scrub “empty / no crowd / all alone” when crowd is tracked present (rewrite toward “a few people still”).
- Scrub “you step outside” if still indoor; “you enter the building” if still outdoor — unless SNAPSHOT says the location type changed.
- Scrub sudden time skips (“hours later”, “festival is over”, “was not always so”) when time-of-day did not advance.
- Scrub tension drops (“danger passes”) when tension is still high.
- Locations are places, not speakers (“the hall answers” is illegal).
- Atmosphere is FREE: smell, rust, cadence, metaphor, NPC mannerism, sensory flair. Do NOT flag texture adjectives as violations.
- Factual details MUST match SNAPSHOT + ledger: stats, inventory, exits, who is here, HP/MP/XP, damage, quest facts.

Hard-gate UI: repair banner, player draft restored, options like “Look around” / “Check what you carry”, Cancel allowed. No text-turn spend.
