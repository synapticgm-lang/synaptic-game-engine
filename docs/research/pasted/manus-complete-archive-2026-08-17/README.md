# SynapticGM — Complete App Research & Implementation Archive

This archive consolidates the complete **app-related** body of work created in this conversation: SynapticGM product/continuity research, operating and launch materials, comic-mode research and implementation guidance, the quarantined WOF future-title blueprint, raw supporting research outputs, and the original relevant task prompts.

> **Scope boundary:** This archive intentionally excludes the unrelated Hybrid SELV Micro-Climate Cassette engineering/hardware project. The WOF brief is included because it is a quarantined future game-title initiative connected to the broader app portfolio, not to live SynapticGM paths.

## Critical implementation boundaries

| Boundary | Rule |
|---|---|
| Live SynapticGM | WOF and future-title materials must not import into live source, live player data, live prompts, live settings/saves or live Supabase game paths. |
| Story continuity | Bible, opening canon, scene facts, claims, micro-summaries, pins, consequence ledger and locality/perspective controls remain the base; proposed additions are explicit, narrow mechanisms. |
| Comic mode | Treat imagery as a ledger-derived view. Visual output never writes canon, inventory, quest or relationship facts back into the game state. |
| Multiplayer future work | Single-player truth must work first. Public online features are gated behind authoritative state, idempotent inventory/economy, moderation, support and load-test evidence. |
| Commercial/policy materials | Pricing, legal, platform, safety and compliance materials are research/planning outputs that need current qualified review before action. |

## Included-file manifest
