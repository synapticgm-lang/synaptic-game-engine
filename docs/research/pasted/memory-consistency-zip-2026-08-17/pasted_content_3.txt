PRODUCT TRUTH (treat as ground truth)
SynapticGM is a ledger-first AI GM:
- Code owns truth for many things; the LLM writes prose that must obey code outcomes.
- Campaigns come from premade bibles OR Simple/Expert custom (Blank Canvas; Expert accordion with per-section randomize; player bible snapshot).
- Systems include: LitRPG, isekai/summon, story RPG, tabletop fantasy, PYOA.
- Opening establishment gathers name / look / kit / place (and folk/world-shape where relevant), can pick a seeded openingHook, free opening covers, then story-start honeymoon text turns (Free +8 / Mid +5 / High +3).
- Turn loop roughly: mediate input → parse intent / ground action → optional code combat / checks / outcome token → build system prompt + situation packet + memory rails → GM proxy call → parse → wardens/scrub/claim grounding → apply state → quests/map/inventory/System windows → optional memorable image → capacity spend/refund.
- Already present (extend, don’t reinvent): campaign bible, opening canon, sceneFacts, claim grounding, pins, consequence ledger, micro-summaries, anti-recycle talk, perspective + locality wardens, prose wardens, intent parser, speech/protest gate, ledger combat, checkMath/outcome tokens, quest journal + Guide Book lock, dungeon seed + fog map vs street map, Salvage (not street merchant), inventory/paper-doll, themes/shop cosmetics, Kid Mode + Families bar, memorable moments (opener/death/boss/writer-offer), capacity ledger + packs, rewarded ads for memorable, OpenRouter/hosted/BYOK paths, cloud save, Settings perspective, custom tabletop rules paste, System jargon filter, refund on empty/abort/fail, cancel/timeout paths.
- Authority law to respect: player correction > pinned canon/opening invariant > accepted state transactions > scene manifest > supporting evidence > draft invention (color only).
- Competitive / continuity briefs may already exist. This brief may reference those ideas but MUST go wider: full player experience across first minute, first hour, long campaign, monetization feel, UI clarity, safety, and delight. Still include concrete continuity schemas and hard gates — do not hand-wave them.
