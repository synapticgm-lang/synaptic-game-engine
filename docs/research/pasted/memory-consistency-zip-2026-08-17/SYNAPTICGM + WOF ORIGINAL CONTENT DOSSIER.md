## WOF II-C — Monster-collecting world: Gloamwild full v1 data

### Collection fantasy rules

| Rule | v1 implementation |
|---|---|
| Meet | Observe in authored habitat/encounter; field note records time, region, behavior and source. |
| Accord | Use an **accord token** only after a legal condition: lowered Resolve, completed trust action, or nonviolent habitat task. |
| Refusal | Grants field note; local wariness increases temporarily; no shame loop or forced re-encounter. |
| Release | Returns accorded creature to compatible recorded habitat and can yield non-exclusive field material. |
| Party / reserve | Party 4; reserve 48; named accord entries have unique IDs/provenance. |
| Bond ranks | New Accord → Steady → Trusted → Kindred. Bond comes from legal activity/rest/care, not paid boosts. |
| Fatigue | 0–100; high fatigue lowers FOC and blocks risky expedition selection until rest. |
| Wild / bonded / rival-bonded | Wild obeys habitat; bonded obeys owner record; rival-bonded is unavailable for accord. |
| Breeding / trading | **No breeding, no trading in single-player v1.** |
| Fairness | No paid bind boosts, no hard rarity pity tied to spend. Repeated valid exploration can reveal one habitat clue. |
