TARGET DELIVERABLES (12 Items)

D1: Encounter Bible Constitution
Format: Markdown specification + design principles
Contents: Four-phase encounter lifecycle
- Telegraph patterns catalog (STATUS, NPC, scene, item, faction)
- Stakes clarity rules (win/lose/flee/negotiate outcomes)
- Resolution mechanics principles (deterministic core, GM narrates flavor)
- Aftermath receipt types (XP, loot, faction, quest, NPC, dungeon)
- Biome-appropriate spawn rules (no wrong-bible encounters)
- Density targets (FO3-like, not MMO)

D2: LitRPG Encounter Library (8 Templates)
Format: 8 encounter templates (JSON schema + prose example for each)
Contents: Hub ambush, dungeon trash, miniboss, boss, arena duel, faction raid, patrol, wandering elite
- Per-template: Telegraph, stakes, resolution, aftermath, biome filter, turn window

D3: DnD Encounter Library (8 Templates)
Format: 8 encounter templates (JSON schema + prose example for each)
Contents: Combat, trap hazard, skill check, environmental hazard, NPC duel, dungeon puzzle, boss fight, random encounter
- Per-template: Telegraph, stakes (d20 + modifier vs DC), resolution, aftermath

D4: RPG Encounter Library (8 Templates)
Format: 8 encounter templates (JSON schema + prose example for each)
Contents: Social standoff, betrayal crisis, deadline pressure, faction confrontation, moral dilemma, exposure threat, leverage negotiation, ambush
- Per-template: Telegraph, stakes, leverage resolution, aftermath

D5: PYOA Crisis Library (Per-Bible, 5-8 Each)
Format: Crisis templates for 3-5 PYOA bibles (Thornferry, Vesper Glass, Erebus-9, etc.)
Contents: Per-crisis: Telegraph, fork labels, exclusive facts, delayed payoff, ending path, convergence
- Example: Millstone Charter (Sign/Reject), Trust Miller (Trust/Doubt), Bandits or Villagers, etc.

D6: Telegraph Pattern Catalog
Format: JSON catalog + prose examples
Contents: STATUS alert patterns, NPC warning patterns, scene cue patterns, item hint patterns, faction intel patterns

D7: Stakes Clarity Templates
Format: JSON stakes schema + prose templates
Contents: Win outcomes, lose outcomes, flee outcomes, negotiate outcomes, partial outcomes

D8: Resolution Mechanics Spec
Format: TypeScript interfaces + resolution algorithms
Contents: Combat resolution (HP ledger, damage calc, flee check, parley check), skill check resolution (d20 + modifier vs DC), leverage resolution, crisis resolution

D9: Loot Table Design
Format: Tiered loot tables (trash, elite, boss) per mode
Contents: LitRPG loot (gold + weapons + consumables), DnD loot (gold + magic items + quest items), RPG loot (favors + intel + faction access)

D10: Biome-Appropriate Spawn Matrix
Format: CSV matrix (bible × biome × encounter types)
Contents: Per-bible encounter lists with biome filters, wrong-bible exclusions, drought picker logic

D11: Density Targets & Enforcement
Format: Density rules table + enforcement logic
Contents: LitRPG dungeon density (4-6 trash, 1-2 miniboss, 1 boss per 10-room dungeon), DnD Keep density, RPG hub density, PYOA crisis density, turn-based drought, location-based minimums

D12: Implementation Backlog + Eval Harness
Format: CSV backlog (30-40 tasks) + JSON eval gates
Contents: P0/P1/P2 tasks + five quality gates
- G1: 100% encounters resolve with receipt (no 0-receipt runs)
- G2: 80%+ encounters show telegraph (STATUS, NPC, or scene)
- G3: 0 wrong-bible spawns (biome filter works)
- G4: Density targets met (dungeon has 4-6 trash, 1 boss)
- G5: Aftermath receipts present (XP + loot + faction + quest)

DESIGN QUESTIONS TO RESOLVE

1. Template depth: 3-5 minimal / 5-8 standard (RECOMMENDED) / 10-15 comprehensive
2. Telegraph strictness: Always / Most (80% warn, 20% ambush) (RECOMMENDED) / Optional
3. Resolution complexity: Fully deterministic / Hybrid (deterministic core, GM flavor) (RECOMMENDED) / GM-narrated
4. Loot granularity: Generic / Typed for boss/elite, procedural for trash (RECOMMENDED) / Procedural all
5. Biome filter: Hard filter (code blocks) (RECOMMENDED) / Soft filter (GM rail) / No filter
6. Density enforcement: Turn-based / Location-based / Both combined (RECOMMENDED)

Recommendation: Use defaults above unless research uncovers compelling evidence otherwise.
