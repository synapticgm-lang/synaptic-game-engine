# Map Chrome Prompt Library

**Status:** **ORIGINAL SynapticGM** generation material.  
**Scope:** Decorative map surfaces and ornaments only. Existing original parchment and topographic assets under `public/maps/` remain shipped facts; these prompts are optional expansion fuel, not a replacement architecture.

> **Universal negative prompt:** people, faces, hands, characters, creatures, flags, heraldry, national borders, real-world coastlines, readable labels, letters, numbers, coordinates, scale text, signatures, watermarks, logos, brand marks, copyrighted-world references, copied historical map, modern satellite imagery, UI screenshot, quest marker, location pin, blood, gore, sexualized forms.

## Production Rules

| Role | Required properties |
| --- | --- |
| Parchment | Seamless or edge-aware paper material; preserve a quiet central field; no writing, seals, crests, or printed grids unless explicitly requested as abstract illegible marks. |
| Topographic grain | Use plausible contour rhythm without claiming measured elevation. Decorative contours must never be presented as real survey data. |
| Compass ornament | Use original radial geometry based on circles, rays, petals, waves, and simple cardinal balance; no copied historical rose, insignia, or readable direction letters. |
| Floor-plan fill | Generate tiling architectural materials or abstract plan hatching. Do not invent exits, doors, room labels, traps, or navigable geometry for a live map. |
| Safety | Kid-safe material design. Bone, ash, infernal, or haunted variants stay abstract and non-graphic. |

## Output Acceptance Gate

| Check | Pass condition |
| --- | --- |
| Originality | No recognizable real map, historical ornament, brand mark, game UI, or franchise symbol. |
| Text safety | No readable text, pseudo-letters that resemble a title, coordinates, or accidental signature. |
| Geometry honesty | Decorative grain does not claim measured elevation, navigable exits, or actual location relationships. |
| Tiling | Seamless prompts repeat without seams, directional lighting discontinuity, or obvious duplicated hero objects. |
| Live readability | Contrast remains subordinate to walls, labels, tokens, and player-facing copy. |
| Kid Mode | No graphic remains, body horror, sexual content, gambling cue, or frightening focal subject. |
