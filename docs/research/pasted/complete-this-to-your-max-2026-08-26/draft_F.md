# Draft F — Engineering evaluation fixtures

> The fixtures below are deterministic contracts. Image semantic cases are evaluated in a fixed human-reviewed rollout set or by explicit metadata/user report; they do not require a Continuity-Warden or second critic model in the live path.

## F) Eval fixture pack

### F.2 FAIL / must reject or degrade

| ID | Test level | Setup | Expected hard outcome | Owning module(s) |
|---|---|---|---|---|

| **R02 Wrong speaker bubble** | Component | Overlay payload binds utterance `u17` to `c_ben` while accepted store says `c_ana` | Render fails closed or rebinds from accepted utterance record; no bubble appears with Ben as speaker | `SpeechBubble`, accepted text store |

| **R05 Invented NPC in generated art** | Sampled image/user repair | Prompt required one focal character; output visibly adds a second person | Panel is hidden or user-marked for simplify/retry; it cannot create a ledger entity, dialogue speaker, target, or relationship | `generateComicImage`, `ComicGrid` repair UX, ledger boundary |
| **R06 Wrong weapon** | Sampled image/user repair | Canonical equipped weapon is brass spear; art shows bow | Panel is rejected/hidden or repaired with simplified composition; story inventory/equipment remains unchanged; wrong art is not reused in recap | kit-lock compiler, `visualConsistency`, `generateComicImage`, `memorableMoments` |
| **R07 Wrong place** | Sampled image/user repair | Committed place is glasshouse; output shows an outdoor desert | Panel does not attach or is immediately removable; no place mutation; retry may use stronger anchors or deterministic background | `visualConsistency`, `generateComicImage`, `ComicGrid` |
| **R08 Kid safety leak** | Safety/E2E | Unsafe framing or gore glamour reaches an output despite preflight | Output never renders to the child; job is quarantined/failed; incident telemetry fires; automatic paid reroll is off unless a safe rewritten PanelSpec is created and policy permits | Kid gate, edge `generate-image`, `generateComicImage` |
| **R09 Director/planner invents damage** | Contract | Optional planner outputs “broken arm” though accepted ledger records no injury | Plan validation rejects the panel plan and falls back to deterministic template/no art; ledger and prose are untouched | optional planner adapter, `comicScriptAdapter`, ledger binder |
| **R10 Art blocks input** | E2E | Pending image promises never resolve | Test fails if choices/text input are disabled, focus is trapped, or turn commit awaits art; production behavior must keep play interactive | `useGame`, `ComicGrid` pending state |
| **R11 Double capacity debit** | Integration/accounting | User double-clicks retry; network retries the POST; two workers receive same job | Exactly one logical reservation/debit for the same idempotency key; duplicate request returns existing state; any duplicate debit is a release blocker | `generateComicImage`, edge `generate-image`, capacity ledger |
| **R12 Stale art after correction** | E2E | Turn revision 1 queues art; user/GM correction commits revision 2; revision-1 art finishes later | Revision-1 result is stored as stale or discarded and never attaches/reuses; only revision-2-compatible asset may render | `useGame`, `generateComicImage` revision guard, `memorableMoments` |
| **R13 Franchise or living-artist prompt leak** | Contract/safety | User or GM tag requests a named publisher, title, franchise, or living artist | Style target is removed/replaced with an original internal technique bundle or generation is skipped; prohibited term never reaches hosted model | `parsePanels`, style-token compiler, `comicImagePrompt` |
| **R14 Over-budget page** | Contract | Webtoon plan emits three panels or paged plan emits four during live turn | `panelBudget` clamps/rejects before spend: webtoon ≤2 and live global ceiling ≤3; removed panels do not reserve capacity | `panelBudget`, `comicScriptAdapter`, job scheduler |
| **R15 Art adds canonical outcome** | E2E/ledger | Image depicts defeated enemy, opened vault, or transferred item not present in committed text | UI labels art noncanonical and hides/rejects it; no parser reads outcome back into ledger; choices remain based on accepted state | `generateComicImage`, `ComicGrid`, ledger boundary |
| **R16 Overlay anchor outside vocabulary** | Contract/component | Planner emits `center-left` or arbitrary x/y for canonical bubble | Plan fails schema validation or maps through an explicit card fallback; only five existing anchors reach overlay components | `comicScript` types, `comicScriptAdapter`, overlay components |
| **R17 Same-beat duplicate spend** | Integration | Player repeats look-around with no ledger/place/roster/kit change and a valid plate already exists | Eligibility gate skips a new job and reuses plate/chrome or text-only state; zero new debit | beat dedupe, `memorableMoments`, `panelBudget` |
| **R18 Classic regression** | Regression | `visualMode=classic` with comic settings left in storage | Test fails if `ComicGrid`, multi-panel queueing, or comic-only layout changes appear; Classic can use only shared plate chrome | Settings, `useGame`, Classic renderer |

### F.3 Fixture execution matrix

| Fixture class | CI on every change | Release-candidate suite | Human sampled rollout |
|---|---|---|---|
| Schema, source precedence, panel budgets, anchors | Yes | Yes | No |
| Overlay speaker/text/accessibility | Yes | Yes on target devices | Spot-check |
| Non-blocking, idempotency, stale revision | Yes with mocked provider | Yes with staging provider | Telemetry audit |
| Prompt/roster/kit/place compilation | Yes via golden strings/structured snapshots | Yes | Sample output review |
| Image semantic adherence and text leakage | No model critic in CI | Fixed generation fixture set | Yes, blinded reviewers plus player repair telemetry |
| Kid pre-spend and quarantine behavior | Yes with policy fixtures | Mandatory | Safety review before widening |

### F.4 Release invariant

Any confirmed **double debit, stale attachment, Kid safety render, input-blocking wait, Classic regression, or art-to-ledger mutation** is a release blocker. Wrong roster/place/major kit above the rollout threshold pauses frequency or panel-count expansion even if transport metrics are healthy.
