## Use order

1. Read `technical_engineering_package.md` to understand the architectural baseline, mechanical/piping/electrical schematics and working patent draft.
2. Use the OpenSCAD, firmware, CFD and SPICE source files only in a controlled engineering-development workflow.
3. Use the six operational documents for controlled IP, procurement, testing and licensing preparation.
4. Use the final suite for wiring, DFMEA, technical-file planning, operations/manual drafting and grant narrative.

> **Important:** The package is a conceptual development suite. It is not a safety certification, conformity declaration, construction release, patent filing, site-specific structural design, grid connection approval or product test report. Qualified engineering, legal, product-safety and compliance review is required before any build, energisation, field test, filing or market placement.
