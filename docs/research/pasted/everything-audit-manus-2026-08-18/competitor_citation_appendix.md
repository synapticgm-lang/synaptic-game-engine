## Citation Handling Rules Applied

| Rule | Application |
|---|---|
| Marketing vs behavior | A company’s own page is recorded as the company’s claim/documentation. It is not treated as an independently measured result. |
| No invented metrics | No competitor DAU, retention, token cost, reliability rate, memory accuracy, or revenue is asserted without a source. |
| Unknown is a result | Summon Worlds and RPG Stories are marked limited/unverified where detailed public implementation evidence was not located. |
| Public docs are not source code | Architecture language such as “memory,” “engine,” or “AI” is not expanded into undocumented implementation assumptions. |
| Legal materials | FTC material identifies questions/controls; it does not determine SynapticGM’s legal obligations. |
| Pricing materials | Public list prices demonstrate cost dimensions only. SynapticGM must use its own invoices/CostEvents for actual economics. |
