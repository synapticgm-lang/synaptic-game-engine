## What we explicitly do NOT use

- Plot, chapter text, or dialogue from any named book
- Character names, unique magic, skill names, class trees, or distinctive places from those series
- Series titles in play, picker copy, or writer prose (except the bible `licenseNote`, which says we are **not** based on them)
- VR-MMO / logout-button plots, licensed game worlds, or other closed IP
- WOF races, places, or factions (later project — not this bible)

## Original tropes The Summoned Pact WILL use

SynapticGM names only:

- **Earth origin** — clothes and pockets; permanent displacement; no return button
- **Hero / villain summon** — `[Pactborn]` vs `[Calamity Mark]`; player choice, not a forced allegiance
- **System as in-world** — blue panel, classes, Appraisal, unidentified `[Circle Blessing]` with a cost
- **Inn hub** — The Weighing Cup (cathedral-close common room)
- **Guild hub** — Valespire Contract Hall (posted jobs, rank boards, politics)
- **Dungeon** — Cathedral Undercroft (numbered floors; fog on unvisited rooms)
- **Healer-who-fights** — a possible class or Blessing path, not a copied protagonist
- **World** — Pellane / Valespire / Ash Court / Sevenfold Circle / The Scale
