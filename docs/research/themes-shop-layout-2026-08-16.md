# Themes + Shop layout — what people actually like

**Date:** 16 Aug 2026  
**Product:** Live SynapticGM hub (`ThemesTab` / `ShopTab`). Not WOF.  
**Sources:** Fortnite locker (not the rotating item-shop dump), Destiny appearance screen, Roblox catalog cards, Discord Shop, VS Code / Cursor theme picker, Notion Template Gallery, mobile collection UX (Baymard / Depict).

---

## What testers praise (copy these)

1. **Category chips, not a dump.** Horizontal pills (Outfits / Emotes; Catalog hats / faces; Discord Browse filters; Notion category tiles). People jump, they do not scroll an undifferentiated wall.
2. **One featured, then a compact grid.** Notion’s winning pattern: featured + row-of-tiles, top children visible, the rest collapsed. Mobile collections: **two tiles per row**, hero under ~40% of the first screen — not an autoplay carousel.
3. **Locker ≠ shop.** Fortnite’s *old* locker and Destiny’s appearance screen: equipped look stays visible; the grid is owned items. Shop is a separate shelf. Mixing “buy this dump” into the locker is what people hate about Fortnite’s item shop.
4. **Expand one.** Destiny: tap a slot, browse that slot. Notion / category-preview UIs: one open card, the rest stay tiles. Testers punish never-ending open kits.
5. **Live preview + confirm.** VS Code: arrow-key preview, Enter to keep. Sticky preview of the current look; Save is a thumb-zone CTA (Notion mobile, collection pages).
6. **Owned / equipped is a badge, not opacity trivia.** Roblox + Discord: price vs Owned/Included on the tile. Fortnite Ch5 hid rarity and people got lost.

## What to avoid

- **Fortnite Item Shop dump** — infinite rotating cards, no “my look.”
- **Fortnite Ch5 locker** — extra clicks to favourite, no back-to-top, status hidden, seven tabs per skin.
- **Desktop mega-grid squeezed onto a phone** — unreadably small tiles.
- **Hamburger-only filters** — 75% of mobile shoppers bounce if they cannot refine in one tap.
- **Every kit open at once** — font samples, dice, Hear, and frames belong on the *expanded* card, not on every row.

No Blizzard / Epic / Bungie / Roblox IP in our copy. Patterns only.

---

## Recommended hub (mobile-first)

**Themes = locker.** Sticky live preview (swatch + dice + story type + Hear). Sticky chips: **Sets · Customize**. Compact **2-col** race-set tiles (material chip + dice + name + Equipped/Owned). **One** selected set expands full-width for kit parts. Customize stays an accordion (one slot). Sticky **Save look**. Extra looks stay behind “More.”

**Shop = shelf.** Sticky chips: **Packs · Sets · Bundles · Extras** (active chip follows scroll). One **Featured set** banner (slim, not a carousel). Sets = same 2-col tiles; tap expands **one** kit (fonts, textured dice, Hear, frames). Bundles as a short 2-col price grid. Extras folded by slot. Owned / Included / Buy (soon) on every tile.

Do not strip paid-kit materials, story typefaces, faceted dice, or Hear.
