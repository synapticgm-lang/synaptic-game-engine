## IP fence

All pack authors must reject franchise names, distinctive creatures, places, artifacts, slogans, plot beats, UI logos and celebrity likenesses. Do not use the discarded dump-error titles: Ember Crown, Pactbeasts of the Lanternwild, Gloamwild, Deepgate Accord, Salt Ledger, Sunloom Circuit or Lantern Run Company. Tide Covenant is a faction; Saltkin, Hearthborn, Lanternfolk and Stonevein are Ash Compact races; Ash Compact is a faction. No world may use another world’s culture as a renamed species.

## What every world pack contains

Each `WOF_<worldId>_Pack.md` contains a unique rules contract; original genre-specific ban list; identity kits; four-start map graph; durable NPCs and canned dialogue; opening/choice/retry decks; code-completeable quest DAGs; species/opponents/collectibles; item/economy/vender data; soloable five-person instance; big instance or genre equivalent; progression tree; Theme Kit labels/hooks; and clone-risk/John’s-call section. The packs treat prose as post-commit narration only: code resolves all measurable outcomes.
