# Duplication audit: one source for everything

Written 27 Nov 2026 (UK time) by Synapticgm against main `9ab6b311`, after John asked (10:15) that nothing in the game be duplicated unless it is absolutely 100% needed. Read this with `CODING.md` and `HISTORY.md` before every brief.

## One source rule

1. **Every piece of logic, data, rule, fact, constant, prompt text and validator has exactly one home.** Extend the home; never add a second copy under any name.
2. **A copy is allowed only when a runtime truly can't import the source.** The only known case is the Deno edge function (`supabase/functions/`), which can't import `src/`. Even then the copy is **generated** by `npm run sync:gm-edge` and checked by `npm run check:gm-edge`. A hand-written copy is never allowed.
3. **Each PR lists the duplication it removed** (file:symbol) under "Duplication removed". A PR that adds a copy fails review.
4. **When a brief touches a file in the table below, it deletes the copies listed for that brief.** "Keep the old one for safety" is not allowed.
5. **Several stores of the same fact count as duplication**, even when the code isn't copied: two places that both hold "who is here", "what the writer knows" or "how many options" will drift.

## How this was checked (and its limits)

- **Text clones:** `jscpd` over `src/` and `scripts/` (12+ lines, 80+ tokens; tests and fixtures excluded) found only 56 clones, about 1% of 165k lines, almost all in dev scripts. So the game's duplication is mostly **re-implementation**: the same job done by different code in several places. Copy-paste detection can't see that.
- **Re-implementation:** found by `rg` for symbols and constants, import-graph counts, and the module headers. That is reliable for the rows below, but **not exhaustive**. Areas not read line by line: the bodies of `useGame.ts` (6,922 lines), `fateAutoplay.ts` (3,645) and `openingEstablishment.ts` (3,754), the component tree beyond what briefs 24/34/35 already cover, `src/data/campaigns/*`, `wof/`, and `tools/`.
- **Edge twins:** every file in `supabase/functions/_shared/gm/` was diffed against `src/` (counts below). `npm run check:gm-edge` printed "edge copies match" on `9ab6b311`.
