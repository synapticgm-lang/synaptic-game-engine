## Cause

`compileNounAllowlist` (`src/game/completedEventPacket.ts:575` before this change) pushed `Object.values(state.routeStops).flat()` onto the mention list. Every stop on every road was handed to the gate, so a stop from another leg passed. `maskPlaceNames` (`src/game/narrativeHarvest.ts:81`) blanked that same full list. Lap 38's four "invented place" kinds were the engine's own stop names sitting in that turn's writer prompt (`YOU MAY ONLY MENTION`). "Nobody met" is no encounter. The saved prompts do not contain the sentence "The way passes …"; the names are on the mention list. `scripts/factCheck.mjs` already left D T14 and B T10 unmarked.

## Fix

The reviewer quotes the prompt line. factCheck exit-place and name flags are the first source.
