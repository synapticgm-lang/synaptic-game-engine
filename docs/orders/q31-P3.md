# q31-P3 — Order P-3: factCheck person/name misreads

Tag `q31-P3`. Order P-3 from `docs/orders/queued-fix-orders.md` (checker misread, scripts only). Only `scripts/factCheck.mjs` changed in logic, and no game or edge file changed. John's ship prompt asked for a stamp, so it ships as `2026-10-15q` on the Vercel git build, with no gm-turn deploy.

## Causes (`scripts/factCheck.mjs`, line numbers at `12726bad`)

1. **People record left out road meetings.** At `:147`, the REF ENUM parse dropped each row's note. At `:193`, `peopleText` took only `person`/`companion` rows. At `:428` and `:434`, `personHere` and `hereCount` took only `person` rows and also excluded `encounter:` rows. A road meeting is a `road:` row of kind `meeting` whose note is its label ("Cutha Cotter, a hurt traveler, …"), so "the hurt traveler", "the farmer" or "the child" after a handed meeting got flagged.
2. **Apposition was not understood** (`:422-424`). The check only accepted a handed name after `called|named|known as`, and only within 30 characters. "a man in a stained apron, Piers Dunmore," got flagged.
3. **Quoted signs** (`:352`). The capitals regex includes `'`, so "reads 'Cathedral Undercroft'" produced `Cathedral Undercroft'`, which never matched the handed place.
4. **Not in the order, found on the tape.** s5003 T12 has no encounter or meeting ref. The flag was on "marked **every** stranger who passed". That is anyone of a kind, not a new person, which is the same class as the existing "role, not the word" rule at `:430-432` (comparisons, might-be).

## Fix (one shared mechanism, no word lists)

- **New `handedPeople(refs)`** (exported). It returns every REF ENUM `person`, `companion` and `meeting` row, each with its display and its label (the note's who-they-are clause, before the first `;`). Rows are shaped like `LedgerRef` (`{ id, kind, display, note }`). `peopleText`, `personHere` and `hereCount` all read this one list. The `encounter:` exclusion is gone.
- **Naming a handed person:** the called/named test and apposition are now one same-clause match on the rest of the narration. The name must be handed (`allowText`) and cannot be the PC's own name.
- **Anyone of a kind:** `every|any` joins the existing role-not-the-word test (comparison / might-be). This extends the rule, not a list.
- **Names:** a trailing quote mark is stripped along with the existing possessive, in the same replace.

### P-2 switch point

When P-2 exports `handedRefs(state, packet)`, factCheck should read its people rows in place of the packet parse inside `handedPeople`. Two options: a JSON dump the replay/autoplay writes next to `writer-prompts/turn-NN.txt`, or `refs` passed straight in. Every caller already goes through `facts.people`, so it is a one-function swap. The script cannot import TS, so the parse stays until P-2 picks one of those.
