# q31-P2 — Order P-2: repeated-habit counts handed labels as habits

Tag `q31-P2`. Builds the one shared `handedRefs(state, packet)` list and switches the habit mask + factCheck people rule onto it.

## Cause

`src/game/turnCheck.ts` `checkPlayCrimes` (~:670) built a handmade `masks` array (HERE, PC name, npcMemories, hubs, `routeNames`) before comparing 5-grams to the last three beats. It never masked this turn's REF ENUM displays/labels (group cast, road-meeting labels, props). A writer that correctly named who was still here ("the two drowned rite novices") was flagged `repeated-habit`.

## Fix

- **`handedRefs(state, packet?)`** next to `compileRefEnum` in `completedEventPacket.ts`: REF ENUM displays + note labels (`note` before the first `;`), plus the journey's handed trip words (ground / from / to / underway HERE line) while `here` is skipped for underway trips. Longest-first mask order preserved without a new regex.
- **`turnCheck.checkPlayCrimes`**: masks = `handedRefs(before)` ∪ `handedRefs(after)` — not a second handmade list.
- **`scripts/factCheck.mjs` `handedPeople`**: same label rule on person / companion / meeting rows (P-3 switch point). Script cannot import the packet builder; the game list stays `handedRefs` for P-5 / M.
- Edge: mirrored via `sync-gm-edge-shared` `completedEventPacket.ts`.
