# q31-L4: push on into the night (ignored action)

Tag `q31-L4`. Stamp `2026-10-16z`. Play change: the writer packet for a push-on travel beat, so the stamp moves. Edge stub `travelJourney.ts` (`writerEngineResult`) changed → `gm-turn` redeploy. Order F and M already shipped; travel is its own scene.

## Cause

- `src/game/travelJourney.ts` `writerEngineResult` (~1019): `/Travel: .*?\./` also matched inside `Extended Travel: …`, so CON-save lines were unsafe next to a Travel receipt.
- `useGame.ts` / `fateAutoplay.ts` put only `travelCommit.receipt` into `engineResultFact`. Extended Travel saves lived on STATUS (`extra`) and never reached the writer.
- On cursed-keep s5002 T5, "Push on into the night" arrived with receipt `now morning`. `writerTravelFact` handed `Arrived at …. It is now morning.` — the night push was ignored.

## Fix

- **`travelEngineLines(commit)`**: Extended Travel lines from `extra` + Travel receipt; when `pushOnSlot` is set (chip was push-on), the receipt's `now <slot>` is the chip's slot (night), not the landing hour.
- **`commitTravelStep`**: records `pushOnSlot` from the clock before `stepAlong`.
- **`writerEngineResult`**: `(?<![A-Za-z])Travel:` so Extended Travel is never rewritten (client + edge stub).
- **`lineHasWrongTimeOfDay`**: when ENGINE RESULT has `now <slot>`, that slot owns the beat (morning prose drops on a night push-on).
- Callers pass `travelEngineLines(travelCommit)` into `engineResultFact`.
- Cuts logged in `tt-cut-log.md` (bare Travel regex, `daySpentFacts`, preamble).
