# q31-N: Malnutrition hold covers only Malnutrition levels (Order N)

SRD 5.2.1 p.185 (Malnutrition) and p.181 (Exhaustion): a Long Rest removes 1 Exhaustion level. Only the levels Malnutrition caused stay until the character eats a full day's food.

## Cause

- `src/game/recoveryRules.ts:165` (at `d882c764`), `exhaustionAfterLongRest`: `if (daysWithoutFood >= STARVE_DAYS)` held **every** Exhaustion level, Extended Travel levels included. The engine never recorded which levels came from starving, so the rest rule could only switch on "is the character starving" and hold everything.
- The starvation tick (`src/game/travelJourney.ts:1720-1725` at `d882c764`) added a level through `exhaust` and forgot where it came from.

## Fix (one shared count, no word lists)

- New `character.malnutritionExhaustion` (`src/game/types.ts`, edge `types.ts` mirror): how many of the current Exhaustion levels came from Malnutrition.
- Starvation tick (`travelJourney.ts` camp): adds the levels `exhaust` actually added to the count.
- A full day's food (a ration eaten or the day already fed by foraging): the two fed branches are now one branch that resets `daysWithoutFood` and `malnutritionExhaustion` to 0 together.
- `exhaustionAfterLongRest`: removes 1 level when `exhaustion > malnutritionExhaustion`; otherwise the level stays with the existing "stays (malnutrition)" receipt line. The `daysWithoutFood >= STARVE_DAYS` hold and its `STARVE_DAYS` import are gone.
- The count lives on `character`, so it rides through the live (`useGame`) and autoplay (`fateAutoplay`) merges exactly as `exhaustion` already does. Old saves have no count (= 0), so their levels come off normally, which is SRD for levels of unknown origin.
- Client-only play change. The edge `travelJourney.ts` is a stub without the camp, and the edge `types.ts` edit is type-only, so `gm-turn` is unchanged and not redeployed.

## Tests

- `ttFix17.test.ts` section 2, rewritten to the Order N rule (the old "Malnutrition still keeps it" asserted the wrong SRD reading, logged in `tt-cut-log.md`):

  - Only Malnutrition levels left: the Long Rest keeps them ("stays (malnutrition)").
  - After a full day's food (rations eaten): the count resets and the next Long Rest removes the level.
