# q31-H: motive variants and group lines into `motiveLinesFor` (Wire-in H)

Tag `q31-H`. Stamp `2026-10-15u`. Play change (the engine's fallback answer line and the answer-repair's backed lines change), so it bumps the stamp and ships the client. Run order: the Audit puts H with C ("C + H") and before M. C is on main (`2fd7fc61`). L6 is covered by M step 4 plus H; R4 tests both, so it waits on M. Wire-in I is not part of this order.

## Cause

- `src/game/npcSheet.ts:219` (`motiveLinesFor`, at `95e2e430`) read `src/data/npcMotiveLines.json`, which held one line per motivation. A person had three lines in total, one per motive, so a repeat came quickly and the answer repair had little to hold the writer to.
- `src/game/npcSheet.ts:234` (`motiveLinesOf`) gave a road meeting only `I want <want>`. A group (thugs, a camp) had no lines of its own. The restless dead also got `I want the living off their ground`, so the engine could quote a meeting the SRD says can't speak (Zombie and Skeleton "can't speak").

## Fix

One data shape and one lookup. No new checker, no exception list.

1. **Data.** `docs/library/npc-motive-variants.json` merged into `src/data/npcMotiveLines.json` as `id → string[][]`: one list per motivation, in the archetype's motivation order, with the shipped line first (checked for all 50 archetypes). Merge fixes: the `dreamer_hopeful` key is matched by position (the library file's "Lift others’ spirits" key was mojibake), and trailing full stops are dropped (the engine quote adds its own comma). `docs/library/npc-group-motive-lines.json` copied to `src/data/npcGroupMotiveLines.json` as `kind → string[][]` (thugs, camp; undead `[]`).
2. **`motiveLinesFor(motive)`** returns the motive's own three lines first, then the first line of each of the archetype's other motives (5 lines). The fallback for a motive with no list is unchanged.
3. **`motiveLinesOf(state, name)`**: a person with saved lines keeps them. A speaker who is the live road meeting (the same `roadMeetingWant` match as before, by label or leader name) speaks that group's lines. The motive is picked by `keyedRng` on the save seed, both trip ends, the start turn and the stretch, so a replay says the same thing. Undead return `[]`, so the repair and the engine line never quote them. Other meetings still say their want.
4. **`motiveAnswer`** keeps a line's own `?` or `!` and leaves out the comma after it (`"Would you like to be friends?" Nia said.`). This is a string check, not a regex.
5. **`withMotiveLines` (load)**: a sheeted person's lines follow their sheet, so old saves get the new variants. Roster people with lines are unchanged. A second pass changes nothing.

Deletions (in `docs/orders/tt-cut-log.md`): `getCompletedTopics` and `hasPurchasedFrom` in `npcMemory.ts` (src and edge). Neither had a caller anywhere. They were cut to hold the rule budget. The data shape change is logged too.
