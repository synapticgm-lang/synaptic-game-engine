# q31-RC3: engine chips recognised by their builder and resolved action, not their label (Order RC-3)

Stamp `2026-10-15x`. Play change (chip filtering), so the stamp moves. No edge copy of the changed files, so no `gm-turn` deploy.

## Cause

- `src/game/choicePipeline.ts:362-385` (at `1ec1f9f9`): `PURE_GENERIC_PAD` and the long label regex in `isLegalEnginePad` were the only way to tell an engine chip from an invented one. Chips are `string[]` and carry no kind, so every builder's new wording ("Scout the exit", a reworded "Wait…") needed another regex entry. Users: `choiceNamesUnnarratedObject` (:418-423) and `choiceWarden.filterInventedContextChoices` (:244).
- `src/game/intentEnums.ts:223/260` (at `1ec1f9f9`): `inferIntent` tested the generic `check` verb before its own status rule, so "Check Status" resolved to an inspect action instead of a status check.

## Fix

- **Builder record (chip id).** `engineChipLabels(state, storyProse)` collects the chips this state's own builders make: `compileChoices` (compiler pads and fallbacks), the beat edges (`choiceEdge`), the graph edges (`graphChoices`), hub pads (`hubArrivalChoicePads`), the PYOA spine and `sceneSafeFallbacks`. The chip type stays `string[]` (the order says not to widen it). The set is built once per state/story and reused for each chip in a list.
- **Resolved action.** If no builder made the chip, it is still the engine's when `inferIntent` resolves it to an engine action and it names nothing the story must have narrated (the same object reader that `choiceNamesUnnarratedObject` already uses, now one helper `concreteChoiceObjects`). Status resolves to INTENT_STATUS (reads the player's own sheet). The order's permitted `travel to` / `talk to` shapes stay.
- **Deleted:** `PURE_GENERIC_PAD`, the label regex and its five shape regexes, the spine label check in `choiceNamesUnnarratedObject` (now part of the builder record), and the duplicate status rule in `inferIntent`. Also dead code with no caller anywhere: `choiceWarden.explainFilteredChoice`, `intentEnums.getIntentLabel` and `intentEnums.isSocialIntent`. All listed in `tt-cut-log.md`.
- An invented "Inspect the crystals breaking the street" is still rejected: no builder made it for that story, and it names an object the story never narrated.
