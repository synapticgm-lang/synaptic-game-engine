# q31-O1C: cleared sites + L2 loot-once

Stamp `2026-10-16l` (from `2026-10-16k`). Play change: cleared interiors condense to `clearedSites` (map as walked + item deltas, no foes); LitRPG reward boxes and dungeon chests loot once. Client path (`dungeonLifecycle` / `dungeonCard` / `achievements` / `looseItems` / exit paths). Edge: dead `entityCast` + `loiterDeltaDirective` stubs removed (no gm-turn behaviour change).

## Cause

- **O1-C** (`dungeonLifecycle.ts` `maybeAutoCloseDungeon` / `closeDungeon`): legacy non-card path discarded the layout on clear; card path parked a full copy but had no compact delta / no shared cleared-site reopen. Re-entry could reseed foes and unopened chests.
- **L2** (`rules/achievements.ts` + dungeon lootables): Bronze Reward Box could be re-granted or double-looted (System open + world "box" search); dungeon chests reseeding after discard enabled the same Worn Jerkin farm. Root: no durable opened/grant record tied to the dungeon-card chest state.

## Fix

- `clearedSites[placeId]` on clear/leave: map topology + visited/cleared + `openedLootableIds` / loose left; item deltas `left` / `moved` / `taken`. Re-entry via `openDungeonCard` / `openDungeonAtSite` applies the record (no foes).
- Legacy auto-close condenses instead of discarding; cards mark `cleared` and write the record on park.
- Reward boxes: `opened:reward-box:…` on the save; `settleDeeds` will not re-grant; `isRewardBoxOpenLine` keeps System opens out of `searchOutsideDungeon`.
- Dungeon-card opened lootables survive clear/leave/re-enter via the cleared record.
